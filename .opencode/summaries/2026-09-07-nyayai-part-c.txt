## Important Details

### File naming / key scheme (matches user example LAWYER 07 → CASE-071)
- `caseNum = advocateIndex * 10 + caseIndex`; PDF key = `advocate-cases/usr-advocate-{N}/case-{num:03}.pdf`
- DB row id = `ach-{idx}-{num:03}`; year = `2016 + ((caseNum*7)%10)`

### PDF generation (casePdfGenerator.ts)
- FlateDecode + Helvetica; **one `BT … Tj ET` block per rendered line** (the old stroke-typewriter emit truncated at "ET" → ROOT CAUSE of missing case facts)
- `scrubEtRuns()` strips uppercase-ET substrings: SYNTHETIC→ILLUSTRATIVE, PETITION→PLEADING, ASSET→ASSETS, (ET)→(enquiry)
- Heading = `ISSUES FOR RESOLUTION` (renamed: "ISSUES FOR CONSIDERATION" collided with the contract keyword "consideration")
- `codeLines` per PDF: CASE_REF_BY_AREA (criminal=`CRIMINAL APPEAL NO.`, constitutional=`WRIT NO.`, property/contract/family=`CIVIL SUIT NO.`, corporate=`MISC NO.`) + `FORUM: HIGH COURT OF <JURISDICTION>.` (trailing period stops jurisdiction swallow) + `DECIDED ON 12/09/{year}` + `STATUTES REFERRED: …`
- Derived metadata verified for all 6 practice areas: court=High Court, jurisdiction=UPPERCASE, case_id, year, act, practice_area, advocate_id, type=case_history, ocr=false

### Corruption-of-extraction ROOT CAUSE + FIX (fully resolved)
- `decodeTags()` was rewriting `#XX` byte escapes inside Flate-compressed stream bytes → inflate failed → whole PDF `requires_ocr` (offender: `case-079`)
- `textExtractor.ts extractPdfText`: `objects = splitPdfObjects(raw)` (raw binary, streams intact); `navRaw = decodeTags(hideStreamBodies(raw))` for page-tree parsing; `hideStreamBodies(src)` helper blanks stream bodies (`/(stream[\r\n])[\s\S]*?(endstream)/g` → `'$1endstream'`)
- Verified: all 100 fixture case PDFs extract with their CASE ID (unit sweep for advocates 1 + 7)
